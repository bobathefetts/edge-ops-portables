Settings

Model

The model runs on another computer. Enter its OpenAI-compatible address (it must support tool calling).

Run limits

A step is one model call. When the conversation passes 70% of the context budget, old tool outputs are shortened and, if needed, the work so far is summarised (full outputs stay in workspace\raw). Roughly 4 characters = 1 token: set the budget to about 3x your model's context window in tokens, or less.

Approvals

Danger. With YOLO, run_command will run ANY PowerShell command without asking, including commands that use the stored admin credentials it can reach. File writes also stop asking. Use this only while you watch.
Read-only network queries (net_query, ssh_query), the knowledge base and the frontier never ask: the read-only gate checks them instead.

Credentials

Lab logins the AI may use for read-only queries. Passwords are encrypted for this Windows user on this computer (DPAPI) in data\credentials.json. The AI only ever sees the names, kinds, user names and notes — never a password.
Add a credential

Scope

The AI can only query hosts listed under Allow, and never those under Deny (deny wins). Nothing is allowed until this is set. One entry per line: an IPv4 address (10.20.30.5), an IPv4 subnet (10.20.30.0/24, /8 or smaller) or a host name pattern (esx01, *.sw4.lab). Names are not looked up in DNS: esx01 does not match esx01.sw4.lab.

Plugins

Plugins are NOT checked by the read-only gate. A plugin is PowerShell code that can do anything your Windows account can do. Trusting a plugin means trusting its code: open its folder and read every .ps1 file first. Untrusted or changed plugins ask before every run.
